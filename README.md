 Animated To-Do List

A responsive and animated To-Do List web application built using **HTML, CSS, and JavaScript**. This project helps users organize daily tasks with an attractive interface, smooth animations, form validation, and browser-based data storage.

 Features

- Add Tasks – Add new tasks to your to-do list.
- Mark as Completed – Click on a task to mark it as completed or pending.
- Delete Tasks – Remove individual tasks from the list.
- Form Validation – Prevents empty inputs, spaces-only inputs, and numbers-only tasks.
- Local Storage – Saves tasks in the browser and restores them after refreshing the page.
- Task Statistics – Displays total, completed, and pending tasks.
- Clear All Tasks – Remove all tasks with confirmation.
- Animated UI – Includes gradient backgrounds, smooth transitions, hover effects, and animated task cards.
- Responsive Design – Works on desktop, tablet, and mobile screens.

 Technologies Used

- HTML5 – Application structure
- CSS3 – Styling, responsive layout, and animations
- JavaScript – DOM manipulation, event handling, validation, and task management
- LocalStorage – Persistent browser storage

 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `todo.html` and `style.css` are in the same folder.
4. Open `todo.html` in your web browser.
5. Start adding and managing your tasks!

You can also use the **Live Server** extension in VS Code to run the application.

 Project Objective

The objective of this mini-project is to practice JavaScript DOM manipulation, event handling, form validation, and localStorage while developing a responsive and user-friendly task management application.
